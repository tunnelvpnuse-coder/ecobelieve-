# OMNILIFE Global Life Super App (Specification + Prototype)

This repository now contains:

- `OMNILIFE_PRODUCT_SPEC.md` — Comprehensive global product specification
- `index.html` / `styles.css` / `app.js` — Lightweight interactive web prototype

## Run the prototype

From the repository root:

```bash
python3 -m http.server 8080
```

Then open:

- `http://localhost:8080`

## Scope note

This is a planning/prototyping artifact that defines product strategy, UX architecture, monetization, and technical blueprint for the OMNILIFE super app. It is not a production backend implementation.
